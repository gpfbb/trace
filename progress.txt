## 2026-04-10 - FIX-001 & FIX-002
- What was implemented
  - FIX-001: Fixed map click listener in AMapViewWrapper capturing stale isDrawingMode value. Added isDrawingMode and isEditingFence as dependencies to the LaunchedEffect, and read state values directly in the listener callback.
  - FIX-002: Added onFenceClick callback to TopStatusIsland and onHighlightClick to FenceListDialog. Connected to app.setHighlightedFenceId() to enable toggling highlight on/off.
- Files changed

  - app/src/main/java/com/trackmaster/app/ui/screens/MapScreen.kt
  - prd.json
- **Learnings for future iterations:**
  - Pattern: LaunchedEffect in Compose only re-runs when its key dependencies change. If a State variable is read inside a LaunchedEffect but not used as a key, the effect won't re-run when the state changes - the closure will capture stale values.
  - Pattern: When setting up listeners inside LaunchedEffect that depend on State variables, always add those State variables to the effect's key list.
  - Gotcha: AMap setOnMapClickListener captures closure variables at setup time. If isDrawingMode changes after the listener is set, the listener will still have the old value unless the effect re-runs.
  - Gotcha: MapScreen already had highlightedFenceId state from app.highlightedFenceId.collectAsState(), so we just needed to wire up the UI callbacks to trigger it.
